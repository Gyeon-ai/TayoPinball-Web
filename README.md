# 타요 핀볼

구슬을 물리 엔진으로 굴려 당첨자를 뽑는 독립 실행형 웹 추첨기입니다. 원본
[Marble Roulette](https://github.com/lazygyu/roulette)를 기반으로 하며, 별도의 광고·분석 코드 없이 동작하도록 정리했습니다.

## 주요 기능

- 쉼표 또는 줄바꿈으로 참가자 입력
- `이름*3` 형식으로 같은 참가자의 구슬 수 지정
- `이름/3` 형식으로 구슬 무게 지정
- 여러 핀볼 맵 선택
- 첫 번째, 마지막 또는 지정 순위 당첨자 선택
- 스킬 항상 활성화 및 방송용 고정 다크 테마
- 이름별로 고정 배정되는 타빡이 구독 퍼스나콘 구슬 스킨
- 당첨자 확정 후 중앙에서 시간을 설정하고 직접 시작하는 카운트다운 오버레이
- 경기 중 즉시 적용되는 1x·2x·5x 배속 버튼
- `?names=철수,영희` URL 파라미터로 명단 자동 입력
- 브라우저 로컬 저장 및 PWA 오프라인 캐시

## 실행

Node.js 20 이상과 pnpm이 필요합니다.

```powershell
pnpm install
pnpm dev
```

개발 서버는 기본적으로 `http://localhost:1235`에서 열립니다.

## 배포 빌드

```powershell
pnpm build
```

정적 배포 파일은 `dist` 폴더에 생성됩니다. 상대 경로로 빌드되므로 GitHub Pages,
Cloudflare Pages, Netlify 또는 일반 웹 서버의 하위 경로에서도 사용할 수 있습니다.

## 기존 수집기 연결

현재 Windows 수집기에서 사용하는 `PinballUrl` 값을 이 사이트의 배포 주소로 바꾸면
기존 `?names=` 명단 전달 기능을 그대로 사용할 수 있습니다.
